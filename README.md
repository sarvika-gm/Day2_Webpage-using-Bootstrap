# Day 2 – Personal Portfolio Website Using Bootstrap

## 📌 Project Overview
As part of my internship, I developed a personal portfolio website using HTML, CSS, and Bootstrap. The website showcases my profile, technical skills, projects, educational background, certifications, and contact information.

## 🎯 Objectives
- Create a professional and responsive personal portfolio.
- Practice HTML, CSS, and Bootstrap.
- Display technical skills and project experience.
- Provide easy access to my resume and professional profiles.
- Improve frontend development skills.

## 🛠️ Technologies Used
- HTML5
- CSS3
- Bootstrap 5.3.8
- JavaScript

## ✨ Features
- Responsive navigation bar
- Profile section with image
- About Me section
- Professional Skills with animated skill bars
- Projects and Experience section
- Project details using pop-up modals
- Education and Certifications section
- Area of Interest and Soft Skills
- Downloadable resume
- Contact and social media links
- Smooth scrolling and hover effects
- Back-to-top button

## 🎨 Design
The portfolio uses a **Lavender and Pink** color theme with a split hero layout. The design is responsive and adapts to different screen sizes.

## 🚀 How to Run the Project
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure the image and resume files are in their correct folders.
4. Install the Live Server extension in VS Code.
5. Right-click `index.html`.
6. Select **Open with Live Server**.
